# Brain-Radiology-Project
A deep learning pipeline for multi-class brain tumor classification (Glioma, Meningioma, Pituitary, No Tumor). Trained on the Kaggle Brain Tumor MRI Dataset (7,023 images). It evaluates 5 pre-trained CNNs: VGG16, ResNet50, DenseNet121, EfficientNetB0, and MobileNetV2 via transfer learning to identify the most accurate medical architecture.
